Report a work item

Flat owners can add individual issues. For shared spaces, choose “Common area” and select the floor or building-wide location.

You can add multiple problems together. Enter each problem on a new line; every line will appear as a separate item in the work register.

Shared access

No account or email sign-in is required. Anyone with the website link can view, add, and change the status of work items.

Demo mode: changes are saved only in this browser. Connect Supabase for shared updates.
